# Backend agents

The Python agent services are configured from the repository-root `.env` file. See the [main setup guide](../README.md#getting-started) for installation and startup instructions.

The default launcher starts `momo_agent.py`, `medirescue_advisor.py`, `insurance_agent.py` and `research_agent.py`. `financial_advisor.py` is an additional module and is not included in the default launch flow.
